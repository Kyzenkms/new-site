## Unit 1 — Integral Calculus

### Topics
1. Review: area, volume, length, surface area using simple integration
2. Volume of solid of revolution
3. Improper integrals
4. Differentiation under integral sign (Leibniz rule)

### 1.1 Review formulas (area, volume, length, surface area)

**Area under a curve** y = f(x), x = a to b:
**A = ∫ₐᵇ y dx = ∫ₐᵇ f(x) dx**

Area between two curves y = f(x) and y = g(x) (f ≥ g on [a, b]):
**A = ∫ₐᵇ [f(x) − g(x)] dx**

**Length of curve** y = f(x), x = a to b:
**L = ∫ₐᵇ √(1 + (dy/dx)²) dx**

**Surface area of revolution** (curve y = f(x) rotated about x-axis, x = a to b):
**S = 2π ∫ₐᵇ y √(1 + (dy/dx)²) dx**

**Volume of solid of revolution** (about x-axis — the classic disc/washer formula):
**V = π ∫ₐᵇ y² dx** (when y = f(x) rotated about x-axis)

About y-axis: **V = π ∫_cᵈ x² dy** (curve x = g(y), y = c to d)

Pappus centroid theorem (quick shortcut): volume generated by revolving a plane area A about an external axis = A × (distance travelled by its centroid). **V = A · 2πR**, where R = distance of centroid from the axis.

### 1.2 Worked examples

**Example 1 — Volume of revolution.** Find the volume of the solid formed by revolving y = √x, x = 0 to 4, about the x-axis.

V = π ∫₀⁴ y² dx = π ∫₀⁴ x dx = π [x²/2]₀⁴ = π · 8 = **8π cubic units**.

**Example 2 — Arc length.** Find the length of the curve y = (2/3)x^{3/2} from x = 0 to x = 3.

dy/dx = x^{1/2}. So L = ∫₀³ √(1 + x) dx. Put u = 1+x, du = dx:
L = ∫₁⁴ √u du = [(2/3)u^{3/2}]₁⁴ = (2/3)(8 − 1) = **14/3 units**.

**Example 3 — Area between curves.** Find the area enclosed between y = x² and y = x.

Intersection: x² = x ⇒ x = 0, 1. On [0,1], x ≥ x², so
A = ∫₀¹ (x − x²) dx = [x²/2 − x³/3]₀¹ = 1/2 − 1/3 = **1/6 sq units**.

### 1.3 Improper integrals

An integral is **improper** if (a) a limit of integration is infinite, or (b) the integrand blows up (discontinuous) at some point inside the range.

∫ₐ^∞ f(x) dx = lim_{b→∞} ∫ₐᵇ f(x) dx — **converges** if the limit exists finite, else **diverges**.
∫ₐᵇ f(x) dx with a singularity at c ∈ (a,b) = lim_{h→0⁺} ∫ₐ^{c−h} + lim_{k→0⁺} ∫_{c+k}ᵇ — both must converge independently.

Key test results:
- **∫₁^∞ dx/xᵖ converges ⟺ p > 1** (and equals 1/(p−1)).
- **∫₀¹ dx/xᵖ converges ⟺ p < 1**.
- **Beta function:** B(m,n) = ∫₀¹ x^{m−1}(1−x)^{n−1} dx = **Γ(m)Γ(n)/Γ(m+n)**, m,n > 0.
- **Gamma function:** Γ(n) = ∫₀^∞ x^{n−1} e^{−x} dx; **Γ(n) = (n−1)Γ(n−1)**; Γ(n) = (n−1)! for integer n; **Γ(1/2) = √π**.

**Worked example.** Check convergence of ∫₀^∞ dx/(x²+1): = [tan⁻¹x]₀^∞ = π/2 − 0 = **π/2, converges**.

### 1.4 Differentiation under integral sign (Leibniz rule)

If **I(a) = ∫_{u(a)}^{v(a)} f(x,a) dx**, then:

**dI/da = ∫_{u}^{v} (∂f/∂a) dx + f(v,a)·v′(a) − f(u,a)·u′(a)**

Special case (constant limits u = α, v = β):
**dI/da = ∫_α^β (∂f/∂a) dx**

Strategy: to evaluate ∫₀^{π/2} f(x) dx type integrals, introduce a parameter a, differentiate w.r.t. a, integrate the simpler result, then set a to the desired value.

**Worked example.** Evaluate I = ∫₀^{π/2} ln(sin x) dx.

Let I(a) = ∫₀^{π/2} ln(a sin x) dx. Then dI/da = ∫₀^{π/2} dx/a = π/(2a). Integrate: I(a) = (π/2) ln a + C. But I(1) = (π/2)ln 1 + C = C = our integral. Also I(a) = ∫₀^{π/2}[ln a + ln sin x] dx = (π/2)ln a + I(1), consistent. Need another condition: consider I(a)+I'(a)... standard trick gives I(1) = −(π/2)ln 2. **Answer: −(π/2) ln 2.**

(Alternative clean route: note ∫₀^{π/2} ln(sin x)dx = ∫₀^{π/2} ln(cos x)dx; add them: 2I = ∫₀^{π/2} ln(sin x cos x)dx = ∫₀^{π/2}[ln(sin 2x) − ln 2]dx; first term = (1/2)∫₀^π ln(sin u)du = I; so 2I = I − (π/2)ln 2 ⇒ I = −(π/2)ln 2.)

### Unit 1 — Likely exam questions

1. **Q: Find the volume of the solid generated by revolving y = x² from x = 0 to 2 about the x-axis.**
   A: V = π∫₀² x⁴ dx = π[x⁵/5]₀² = 32π/5.

2. **Q: Find the length of the parabola y² = 4ax from the vertex to (a, 2a).**
   A: x = y²/4a, dx/dy = y/2a. L = ∫₀^{2a} √(1 + y²/4a²) dy = 2a∫₀¹ √(1+u²) du (u = y/2a) = a[√2 + ln(1+√2)].

3. **Q: Test the convergence of ∫₁^∞ dx/x³.**
   A: p = 3 > 1 ⇒ converges; value = 1/2.

4. **Q: State and use Leibniz rule to find d/dx ∫₀^{x²} sin(xt) dt.**
   A: I = ∫₀^{x²} sin(xt)dt. ∂/∂x sin(xt) = t cos(xt). dI/dx = ∫₀^{x²} t cos(xt)dt + sin(x·x²)·2x = [−(t/x)cos... integrate by parts] + 2x sin(x³). Simplest direct route: substitute u = xt ⇒ I = (1−cos x³)/x, then differentiate. Model answer accepts the Leibniz-rule setup.

5. **Q: Evaluate ∫₀^∞ e^{−ax} cos bx dx using differentiation under integral sign.**
   A: Start from I(a) = ∫₀^∞ e^{−ax} cos bx dx; consider ∂/∂b of J = ∫₀^∞ e^{−ax} sin bx dx… Standard result: **a/(a²+b²)** (via two differentiations/integration of I″ − b²I-type ODE, or via Laplace transform).

6. **Q: Find the area enclosed by y = 4x − x² and the x-axis.**
   A: Roots at 0, 4. A = ∫₀⁴ (4x − x²)dx = [2x² − x³/3]₀⁴ = 32 − 64/3 = 32/3.

7. **Q: Prove Γ(1/2) = √π (outline).**
   A: Γ(1/2) = 2∫₀^∞ e^{−u²} du (put x = u²); square it, switch to polar coordinates → Gaussian integral = √π.

## Unit 2 — Multiple Integrals

### Topics
1. Double integral
2. Change of variables
3. Change of order of integration
4. Triple integral
5. Applications: area, mass, volume

### 2.1 Double integral

∬_R f(x,y) dA, where dA = dx dy. Evaluate as an **iterated integral**:

**∬_R f(x,y) dA = ∫_{a}^{b} ∫_{g₁(x)}^{g₂(x)} f(x,y) dy dx**

Key points: inner limits may depend on the outer variable; outer limits must be constants. Sketch the region first — always.

### 2.2 Change of variables

For x = x(u,v), y = y(u,v):

**∬_R f(x,y) dx dy = ∬_S f(x(u,v), y(u,v)) · |J| du dv**

where the **Jacobian** J = ∂(x,y)/∂(u,v) = | x_u x_v; y_u y_v | (determinant).

**Polar coordinates** (the most-used change): x = r cos θ, y = r sin θ, |J| = r:

**∬_R f(x,y) dx dy = ∬ f(r cosθ, r sinθ) · r dr dθ**

Use polar when the region is a circle/sector/annulus or integrand has x² + y².

### 2.3 Change of order of integration

Steps: (1) sketch region from given limits, (2) find new limits by slicing in the other direction, (3) rewrite and evaluate. The region stays the same — only the order of dy dx changes to dx dy (or vice versa).

**Worked example.** Change the order in I = ∫₀¹ ∫_x¹ e^{y²} dy dx.

Region: x from 0 to 1, y from x to 1 → triangle with vertices (0,0), (1,0), (1,1). Reversing: y from 0 to 1, x from 0 to y:
I = ∫₀¹ ∫₀^y e^{y²} dx dy = ∫₀¹ y e^{y²} dy = (1/2)[e^{y²}]₀¹ = **(e − 1)/2**.
(Note: the original order is unevaluable — e^{y²} has no elementary antiderivative — so this reversal is the whole point.)

### 2.4 Triple integral

∭_V f(x,y,z) dV, dV = dx dy dz. Iterated with three limits; middle/inner may depend on outer variables.

**Cylindrical coordinates:** x = r cosθ, y = r sinθ, z = z, dV = **r dr dθ dz**.
**Spherical coordinates:** x = ρ sinφ cosθ, y = ρ sinφ sinθ, z = ρ cosφ, dV = **ρ² sinφ dρ dφ dθ**.

### 2.5 Applications

- **Area:** A = ∬_R dA (i.e., f = 1).
- **Volume under surface:** V = ∬_R f(x,y) dA; **volume of a solid region:** V = ∭_V dV.
- **Mass of a lamina:** M = ∬_R σ(x,y) dA, where σ = surface density.
- **Centre of mass:** x̄ = (1/M)∬_R xσ dA, ȳ = (1/M)∬_R yσ dA. If σ constant, use area instead of mass (centroid).

### Worked examples

**Example 1 — Double integral.** Evaluate ∬_R xy dA over the rectangle 0 ≤ x ≤ 2, 0 ≤ y ≤ 3.
∫₀²∫₀³ xy dy dx = ∫₀² x·(9/2) dx = (9/2)·(4/2) = **9**.

**Example 2 — Polar change.** Find the area of the circle x² + y² = a² using double integrals.
A = ∬ dA = ∫₀^{2π} ∫₀^a r dr dθ = ∫₀^{2π} (a²/2) dθ = **πa²**. ✓

**Example 3 — Volume by triple integral.** Volume of the tetrahedron bounded by x = 0, y = 0, z = 0, x + y + z = 1.
V = ∫₀¹ ∫₀^{1−x} ∫₀^{1−x−y} dz dy dx = ∫₀¹ ∫₀^{1−x} (1−x−y) dy dx = ∫₀¹ (1−x)²/2 dx = **1/6**.

### Unit 2 — Likely exam questions

1. **Q: Evaluate ∫₀² ∫₀^x y dy dx.**
   A: Inner = x²/2; outer = ∫₀² x²/2 dx = 4/3.

2. **Q: Change the order of integration in ∫₀^a ∫_0^{√(a²−x²)} f(x,y) dy dx.**
   A: Quarter circle radius a. Reversed: ∫₀^a ∫_0^{√(a²−y²)} f(x,y) dx dy.

3. **Q: Using double integrals in polar coordinates, find the area between r = a and r = a(1 + cos θ).** (or simpler: area of cardioid r = a(1+cosθ).)
   A: A = (1/2)∫_{−π}^{π} a²(1+cosθ)² dθ = (a²/2)∫(1 + 2cosθ + cos²θ)dθ = (a²/2)(2π + 0 + π) = 3πa²/2.

4. **Q: Find the volume of the sphere x² + y² + z² = a² using triple integrals (spherical coordinates).**
   A: V = ∫₀^{2π}∫₀^{π}∫₀^a ρ² sinφ dρ dφ dθ = 2π·2·a³/3 = 4πa³/3.

5. **Q: Find the mass of the lamina bounded by y = x² and y = x with density σ = xy.**
   A: M = ∫₀¹∫_{x²}^{x} xy dy dx = ∫₀¹ x(x²/2 − x⁴/2)dx = (1/2)(1/3 − 1/5) = 1/15.

6. **Q: Evaluate ∭_V z dV where V is the unit cube 0 ≤ x,y,z ≤ 1.**
   A: = (∫₀¹dx)(∫₀¹dy)(∫₀¹ z dz) = 1·1·(1/2) = 1/2.

7. **Q: Using change of variables, evaluate ∬_R (x+y)² dx dy over R: the parallelogram bounded by x+y=0, x+y=2, x−y=0, x−y=2.**
   A: Put u = x+y, v = x−y; |J| = 1/2. Integral = ∫₀²∫₀² u²·(1/2) dv du = (1/2)(8/3)(2) = 8/3.

## Unit 3 — Vector Integration

### Topics
1. Line integral, surface integral, volume integral
2. Gauss divergence theorem (statement + applications)
3. Green's theorem (statement + applications)
4. Stokes' theorem (statement + applications)

### 3.1 Line integral

For a vector field **F** = P **i** + Q **j** + R **k** along curve C (parametrised by r(t), t = a to b):

**∫_C F · dr = ∫_C (P dx + Q dy + R dz) = ∫ₐᵇ F(r(t)) · r′(t) dt**

Interpretation: **work done** by force field F along path C. For a **closed** curve (∮), the value is the **circulation**.

If F is **conservative** (F = ∇φ, equivalently ∇×F = 0 on a simply connected domain), then ∫_C F·dr is **path independent** and **= φ(end) − φ(start)**; ∮ = 0.

### 3.2 Surface integral

**∫∫_S F · dS = ∫∫_S F · n̂ dS** — flux of F through surface S, where n̂ is the unit normal.

For a surface z = g(x,y) projected onto R in the xy-plane:
**dS = √(1 + g_x² + g_y²) dx dy**, and F·n̂ dS = (−P g_x − Q g_y + R) dx dy.

### 3.3 Volume integral

**∭_V f dV** — e.g. total mass if f is density, total charge if f is charge density. Straightforward extension of triple integrals.

### 3.4 The three big theorems (statements)

**Green's theorem (in the plane):** for positively (counterclockwise) oriented closed curve C bounding region R,
**∮_C (P dx + Q dy) = ∬_R (∂Q/∂x − ∂P/∂y) dx dy**

Corollary — **area by line integral:** A = (1/2)∮_C (x dy − y dx) (take P = −y/2, Q = x/2).

**Gauss divergence theorem:** for closed surface S bounding volume V, with outward normal n̂,
**∯_S F · n̂ dS = ∭_V (∇·F) dV**
(Flux through closed surface = volume integral of divergence.)

**Stokes' theorem:** for open surface S with boundary curve C (right-hand rule orientation),
**∮_C F · dr = ∫∫_S (∇×F) · n̂ dS**
(Circulation around boundary = flux of curl through any surface spanning C.)

Memory hook: **Green is Stokes in 2D; Gauss is Stokes "closed up"** — all three convert a boundary integral into an interior integral.

### 3.5 Worked examples

**Example 1 — Line integral (work).** Evaluate ∫_C F·dr for F = x² i + xy j, C: y = x² from (0,0) to (1,1).

Parametrise: x = t, y = t², t: 0→1. dx = dt, dy = 2t dt.
∫_C (x² dx + xy dy) = ∫₀¹ (t² + t·t²·2t) dt = ∫₀¹ (t² + 2t⁴) dt = 1/3 + 2/5 = **11/15**.

**Example 2 — Green's theorem.** Verify for F = (x², xy) i.e. P = x², Q = xy over the unit square [0,1]×[0,1].

∬_R (∂Q/∂x − ∂P/∂y) dA = ∬(y − 0) dA = ∫₀¹∫₀¹ y dy dx = 1/2.
Line integral (4 edges, CCW): bottom y=0: ∫₀¹x²dx=1/3; right x=1: ∫₀¹1·y dy=1/2; top (reversed): ∫₁⁰x²dx=−1/3; left: 0. Total = 1/3+1/2−1/3 = 1/2. ✓ **Both sides = 1/2.**

**Example 3 — Divergence theorem.** Find flux of F = x i + y j + z k through the unit sphere S.

∯ F·n̂ dS = ∭_V ∇·F dV = ∭(1+1+1) dV = 3 × (volume of unit sphere) = 3·(4π/3) = **4π**.

### Unit 3 — Likely exam questions

1. **Q: State Green's theorem and use it to find the area of the ellipse x²/a² + y²/b² = 1.**
   A: A = (1/2)∮(x dy − y dx). Parametrise x = a cos t, y = b sin t: A = (1/2)∫₀^{2π} ab dt = πab.

2. **Q: State the Gauss divergence theorem and find the flux of F = 2x i + 3y j − z k through the unit cube [0,1]³.**
   A: ∇·F = 2+3−1 = 4; flux = ∭ 4 dV = 4.

3. **Q: State Stokes' theorem. Evaluate ∮_C F·dr, F = y i + z j + x k, C the unit circle x²+y²=1 in z = 0 plane (CCW).**
   A: ∇×F = (1,1,1)·? Compute: ∇×F = i(0−1) − j(1−0) + k(0−1) = (−1,−1,−1). By Stokes over the disc: ∫∫(−1,−1,−1)·k dA = −π·1 = −π. (Direct parametrisation x=cos t, y=sin t gives ∮ y dx = −π, others 0 ⇒ −π. ✓)

4. **Q: Show that F = (2xy, x², 0) is conservative and find its potential.**
   A: ∇×F = 0 ✓. φ = ∫2xy dx = x²y + h(y,z); ∂φ/∂y = x² ⇒ h const ⇒ **φ = x²y**.

5. **Q: Find the work done by F = (x + y) i + (x − y) j along y = x³ from (0,0) to (1,1).**
   A: x = t, y = t³: ∫₀¹[(t+t³) + (t−t³)·3t²]dt = ∫₀¹(t + t³ + 3t³ − 3t⁵)dt = 1/2 + 1 + 3/4 − 1/2 = **7/4**.

6. **Q: Evaluate ∯_S F·n̂ dS for F = x³ i + y³ j + z³ k over the sphere x²+y²+z² = a².**
   A: ∇·F = 3(x²+y²+z²) = 3r². In spherical: ∭ 3ρ²·ρ² sinφ dρ dφ dθ = 3·(a⁵/5)·2·2π = 12πa⁵/5.

7. **Q: Distinguish line, surface and volume integrals in one line each, with one physical example of each.**
   A: Line: ∫_C F·dr — work done by a force along a path. Surface: ∫∫_S F·n̂ dS — fluid flux through a membrane. Volume: ∭_V ρ dV — total mass of a solid of density ρ.
